导入题库

GitHub 在线题库

网页会自动读取在线目录。学生只需选择题库和章节，所选章节会下载一次并缓存到当前设备。

一课一练整书导入

选择“题库交付包_V1.0”文件夹。V3 会核对交付清单、九章数量、题量与 SHA-256，再一次导入并加入学习范围。

选择题库根目录

选择任意可读写目录，系统递归查找其中全部章节 ZIP。题库目录只负责读取题库，不再决定学习记录的保存位置。

选择题库文件夹

兼容模式。选择任意文件夹，递归扫描全部章节 ZIP 并缓存到浏览器；不要求固定目录名称。

导入章节 ZIP

一次可多选一个或多个章节 ZIP。同章新版会更新，学习记录保持不变。
GitHub 学习记录同步
学习记录必须使用独立私有仓库
不要把学生记录放进公开题库仓库。令牌只保存在当前浏览器，不会写入网页、题库 ZIP 或 Git 仓库。建议使用仅允许访问记录仓库 Contents 的细粒度令牌。
尚未连接连接后，打开网页会先拉取并合并远程最新记录；本机新增记录会在停止操作约一分钟后回传。
