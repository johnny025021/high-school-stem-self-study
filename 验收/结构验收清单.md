# 基础架构验收清单

- [ ] 根目录统一首页可打开并进入三个学科。
- [ ] 数学、物理、化学页面均为独立 HTML 页面。
- [ ] 每个学科页面均有章节练习、公式记忆、二级结论记忆入口。
- [ ] `题库` 下存在数学、物理、化学三个独立子目录。
- [ ] 每个学科题库下存在三个学习板块子目录。
- [ ] `学习记录` 下存在数学、物理、化学三个独立子目录和 JSON 模板。
- [ ] 三个学科配置使用不同 IndexedDB 名称。
- [ ] 页面能够在 `file://` 下运行，不依赖网络资源。
- [ ] 原 MathBank V3.0.3、PhysicsBank 和冻结题库未被修改。

本清单只验收基础架构，不代表真实题库迁移和学习功能已经完成。
