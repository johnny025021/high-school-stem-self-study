# 题库包统一字段（架构约定）

每个题库 ZIP 的 `manifest.json` 至少应提供：

| 字段 | 说明 |
|---|---|
| `schema_version` | 题库结构版本，当前兼容目标为 1.1 |
| `package_id` | 稳定且全局唯一的题库包标识 |
| `package_version` | 当前题库包版本 |
| `subject_id` | `math`、`physics` 或 `chemistry` |
| `module_id` | `chapter_practice`、`formula_memory` 或 `secondary_conclusion_memory` |
| `library_id` | 书籍或题库大类标识 |
| `book_id` | 具体书籍标识 |
| `chapter_id` | 章节标识 |
| `chapter_name` | 章节名称 |
| `section_id` | 章内课次/节的稳定标识；章节练习题应在题目索引中提供 |
| `section_name` | 学生可见的课次/节名称；同一 `section_id` 必须保持一致 |
| `question_count` | 包内有效条目数 |

统一入口根据 `subject_id` 路由到对应学科，根据 `module_id` 放入对应学习板块。学科页面不得读取其他学科的数据目录或学习记录。

## 统一学习选择层级

章节练习类题库统一采用四级选择：

1. 题库/书籍：由 `library_id` 和 `book_id` 区分。
2. 章：由题库包 `chapter_id`、`chapter_name` 区分，可按需下载和缓存。
3. 课次/节：由题目索引中的 `section_id`、`section_name` 区分，用于跟随学校课程进度缩小练习范围。
4. 题目：在所选课次/节内继续按完成状态、难度、知识点和题型筛选。

如果源题库没有课次/节层级，界面保留“全部已选课次”，直接按章节出题；不得为凑层级虚构 `section_id`。数学、物理、化学后续接入类似书籍题库时均复用这一交互约定。
