# 题库目录

题库分为 `在线题库` 与 `线下题库` 两种交付方式，再按数学、物理、化学和学习板块隔离。

- `在线题库`：适合体积较小、已经发布到 GitHub Pages 的题库。网页按需下载并缓存。
- `线下题库`：适合含高清原书学习页的大体积书籍。学生通过网页的“导入本地 ZIP / 选择线下题库文件夹”一次性导入。
- 已经上线的 `数学`、`物理`、`化学` 三个旧目录属于在线兼容区，保持原路径和文件字节不变，详见 `在线题库/online-path-map.json`。
- 后续新增大体积书籍默认放入 `线下题库/<学科>/章节练习/<书名>/<册次>`，其中 ZIP 已由 `.gitignore` 排除，避免误上传。

正式题库只能使用经过结构校验、资源校验和人工复核的冻结版本；候选包应放在工作区，不应直接晋升为正式题库。
