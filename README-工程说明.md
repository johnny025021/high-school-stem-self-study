# 高中数理化自主学习系统 V1.2.0（GitHub 在线题库版）

## 使用入口

正式使用入口为 [GitHub Pages](https://johnny025021.github.io/high-school-stem-self-study/)。统一首页只负责选择学科，数学、物理、化学分别进入独立界面。本地仍可双击 `启动数理化自学系统.cmd` 进行离线开发和验收。

## 工程边界

- 当前版本完成统一入口、三个独立学科界面、三类学习板块、分学科题库目录、分学科学习记录目录和基础配置。
- 数学页面已完整迁移 MathBank V3.0.3 功能，并升级为 STEMBank 数学 V3.1.1。
- 数学目录只同步《一课一练》上册9个冻结章节包和母题400的21个题库包；未同步培优、期中、期末、月考等其他数学题库。
- 原 MathBank V3.0.3、PhysicsBank 和所有源题库保持不变；新目录中的数学题库均为哈希一致副本。
- GitHub Pages 通过 `data/catalog.json` 发布题库目录。学生选择章节后才下载对应 ZIP，并缓存到当前设备浏览器；首次进入不下载全部题库。
- Pad 点击“分享/下载记录 JSON”时优先调用系统分享面板，可选择微信、文件或其他已安装应用；不支持文件分享的浏览器自动回退为下载。
- 学习记录不得进入公开题库仓库。跨设备自动同步使用独立私有 GitHub 仓库，每台个人设备首次设置一次细粒度访问令牌。

## 独立升级原则

1. 学科页面各自维护 `学科/<学科>/index.html` 和 `app.js`。
2. 题库 ZIP 只进入对应学科、对应学习板块目录。
3. 学习记录导出到对应学科目录，不把三科事件混在同一记录文件中。
4. 浏览器数据库分别使用：
   - 数学：`general_learning_question_bank_stem_math_v1`
   - 物理：`general_learning_question_bank_stem_physics_v1`
   - 化学：`general_learning_question_bank_stem_chemistry_v1`
5. 共享视觉和通用交互放在 `公共资源`；学科业务逻辑不写入统一首页。

## 数学使用路径

1. 从 GitHub Pages 统一首页进入数学。
2. 选择“一课一练”或“母题400”，勾选当前要学习的章节，再点击“应用章节选择”。
3. 网页自动下载并缓存所选章节；也可选择“一课一练整书离线安装”。
4. 数学学习记录实时保存在独立浏览器数据库 `general_learning_question_bank_stem_math_v1`。
5. “分享/下载记录 JSON”在 Pad 上优先打开系统分享面板。
6. “GitHub记录同步”连接独立私有记录仓库后，启动时自动拉取合并，新增记录停止操作约一分钟后自动回传。

## GitHub 发布与隐私

- 公开仓库 [high-school-stem-self-study](https://github.com/johnny025021/high-school-stem-self-study) 保存网页、配置、在线目录和题库 ZIP。
- 私有仓库 `stembank-learning-records` 已建立，只保存 `records/<subject>/<profile>/latest.json`。
- 私有仓库必须预先包含 `main` 分支。令牌只授予该私有仓库的 Contents 读取和写入权限。
- 访问令牌只保存在用户选择的浏览器本地存储中，不得写入任何工程文件或提交到 Git。
- 公共电脑不要勾选“记住在这台个人设备上”；使用结束后点击“断开连接”。
